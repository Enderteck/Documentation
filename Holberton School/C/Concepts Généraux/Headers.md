# Headers

## Définition:

Les headers sont des en-têtes, des fichiers censés êtres inclus au début d'un code pour permettre l'inclusion et le référencement de fonction, sctructures, typesdefs et varibales globales pour tou un projet, même s'il fait plusieurs fichiers.
Il se termine avec un .h et inclut forcément:

```
#define NOM_DE_HEADER
```
